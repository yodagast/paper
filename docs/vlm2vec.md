## 核心贡献

VLM2Vec-V2 提出了一个**统一的多模态嵌入框架**，突破以往仅局限于静态图像的限制，首次实现用统一框架高效提取**图像、视频和视觉文档**的多模态嵌入。主要贡献包括：

1. **MMEB-V2基准**: 扩展MMEB，新增5种任务类型（视觉文档检索、视频检索、时间定位、视频分类、视频问答），共78个任务
2. **VLM2Vec-V2模型**: 支持文本、图像、视频和视觉文档输入的通用嵌入模型
3. **统一嵌入学习策略**: 通过批次混合和交织子批次增强对比学习效果

## 问题背景

### 现有方法的局限

| 方法类型 | 局限性 |
|----------|--------|
| **CLIP/ALIGN** | 仅支持图像-文本对，无法处理交织输入 |
| **VLM2Vec/E5-V/GME** | 主要关注自然图像，视频和视觉文档支持有限 |
| **现有基准** | 评估范围窄，缺乏视频和文档任务 |

### 实际应用场景需求
- AI Agent（多模态理解）
- 多模态搜索和推荐
- 检索增强生成（RAG）
- 文档为中心的知识系统

## MMEB-V2: 全面多模态评估基准

### 基准概述

MMEB-V2在原有MMEB基础上扩展，包含**9个元任务**和**78个任务**：

```
┌─────────────────────────────────────────────────────────────────┐
│                    MMEB-V2 基准结构                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  MMEB原有任务 (蓝色):                                            │
│  ├── 图像分类 (I-CLS)                                           │
│  ├── 图像检索 (I-RET)                                           │
│  ├── 视觉问答 (VQA)                                             │
│  ├── 视觉定位 (VG)                                              │
│  └── ...                                                        │
│                                                                 │
│  MMEB-V2新增任务 (红色):                                         │
│  ├── 视频检索 (V-RET): 视频-文本/视频匹配                        │
│  ├── 时刻检索 (M-RET): 定位视频中的特定片段                      │
│  ├── 视频分类 (V-CLS): 视频类别预测                              │
│  ├── 视频问答 (V-QA): 基于视频的问题回答                         │
│  └── 视觉文档检索 (VisDoc): PDF/PPT/论文检索                     │
│                                                                 │
│  支持模态:                                                       │
│  ├── T (文本)                                                   │
│  ├── I (图像)                                                   │
│  ├── V (视频)                                                   │
│  └── D (视觉文档)                                                │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 新增任务详解

| 任务类型 | 描述 | 查询类型 | 目标类型 |
|----------|------|----------|----------|
| **视频检索 (V-RET)** | 视频-文本/视频匹配 | 文本描述/视频片段 | 相关视频 |
| **时刻检索 (M-RET)** | 定位视频中特定片段 | 文本描述 | 时间段候选 |
| **视频分类 (V-CLS)** | 视频类别预测 | 视频内容 | 类别标签 |
| **视频问答 (V-QA)** | 基于视频的问题回答 | 问题+视频 | 答案文本 |
| **视觉文档检索 (VisDoc)** | PDF/PPT/论文检索 | 文本/文档片段 | 相关文档/页面 |

### 数据来源
- **视频**: YouTube视频、专业制作内容、众包内容（体育、日常活动、电影/电视片段）
- **视觉文档**: PDF报告、PPT幻灯片、科学论文
- **图像**: MMEB原有数据集

### 视频处理策略
- 原始视频均匀采样为帧序列
- 确保训练和评估期间一致的时间覆盖

## VLM2Vec-V2 模型方法

### 模型架构

#### 基础模型: Qwen2-VL-2B

| 特性 | Qwen2-VL-2B |
|------|-------------|
| **参数量** | 2B |
| **嵌入维度** | 1536 |
| **支持模态** | 文本、图像、视频 |
| **优势** | 强多模态理解能力、零样本泛化 |

#### 嵌入提取
- 从最后一层提取最后一个token（EOS）的隐藏状态作为嵌入向量
- 使用余弦相似度度量查询-目标相似性

### 训练方法

#### 1. 数据构建

训练数据包含三大类：
- **视频-指令数据**: 视频描述、问答、检索
- **视觉文档数据**: 文档检索、页面匹配
- **图像数据**: MMEB原有数据

#### 2. 对比学习框架

**损失函数**: InfoNCE Loss

$$
\mathcal{L}_{\text{InfoNCE}} = -\frac{1}{N}\sum_{i=1}^{N}\log\frac{\exp\left(\cos(\boldsymbol{h}_{q_{i}},\boldsymbol{h}_{t_{i}^{+}})/\tau\right)}{\exp\left(\cos(\boldsymbol{h}_{q_{i}},\boldsymbol{h}_{t_{i}^{+}})/\tau\right)+\sum_{t^{-}\in\mathcal{T}^{-}}\exp\left(\cos(\boldsymbol{h}_{q_{i}},\boldsymbol{h}_{t^{-}})/\tau\right)}
$$

其中：
- $\boldsymbol{h}_{q_i}$: 查询嵌入
- $\boldsymbol{h}_{t_i^+}$: 正目标嵌入
- $\mathcal{T}^{-}$: 负目标集合（批内负样本 + 硬负样本）
- $\tau$: 温度参数

#### 3. 批次混合策略 (Batch Mixing)

**核心创新**: 解决多模态数据不平衡问题

```python
# 批次混合策略示意
batch = {
    'image_tasks': sample_image_tasks(ratio_i),
    'video_tasks': sample_video_tasks(ratio_v),
    'document_tasks': sample_document_tasks(ratio_d)
}

# 交织子批次 (Interleaved Sub-batching)
sub_batches = create_interleaved_sub_batches(batch, sub_batch_size)
```

**优势**:
- 确保各模态数据在训练中均衡参与
- 避免某一模态主导训练
- 提升跨模态泛化能力

#### 4. 硬负样本挖掘

负样本来源：
- **批内负样本**: 同批次其他样本
- **硬负样本**: 通过智能挖掘策略选择

#### 5. 指令模板

查询端应用指令模板：

```
Instruct: {task_definition}
Query: {original_query}
```

**任务定义示例**:
- "选择包含海豚的视频片段"
- "检索与查询相关的文档页面"
- "找到与描述匹配的图像"

## 实验结果

### 整体性能

- **新任务表现**: 在视频和文档检索任务上表现出色
- **原有基准**: 在原始图像基准上优于之前的基线
- **78个数据集**: 达到最先进性能

### 关键发现

1. **跨模态泛化**: 图像、视频、文档混合训练不会互相干扰
2. **统一嵌入**: 单一模型可有效处理多种模态
3. **批次混合重要性**: 均衡的批次采样对性能至关重要

---

## 关键技术创新

### 1. 多模态统一框架

| 维度 | 传统方法 | VLM2Vec-V2 |
|------|----------|------------|
| **支持模态** | 单一（图像） | 多模态（图像+视频+文档） |
| **架构** | 分离模型 | 统一模型 |
| **训练策略** | 单任务 | 多任务混合 |

### 2. 批次混合策略

| 策略 | 效果 |
|------|------|
| **单一模态批次** | 模态不平衡、泛化差 |
| **交织子批次** | 模态均衡、跨模态学习增强 |
| **动态采样比例** | 适应不同任务需求 |

### 3. 视频处理

| 维度 | 处理方式 |
|------|----------|
| **帧采样** | 均匀采样确保时间覆盖 |
| **时间信息** | 帧序列保留时序关系 |
| **时刻检索** | 时间段候选匹配 |

## 优势与局限

### 优势
1. **模态统一**: 单一模型处理图像、视频、文档
2. **评估全面**: 78个任务覆盖多种场景
3. **实用性强**: 支持AI Agent、RAG等实际应用
4. **训练高效**: 批次混合策略优化对比学习
5. **泛化能力强**: 跨模态、跨任务泛化

### 局限与挑战
1. **模型规模**: 2B参数可能对某些任务不足
2. **视频长度**: 长视频处理可能有局限
3. **文档复杂度**: 复杂布局文档理解待验证
4. **实时性**: 视频处理计算成本较高

---

## 实践启示

### 1. 多模态嵌入的统一策略
- 统一框架优于分离模型
- 批次混合解决数据不平衡问题

### 2. 评估基准的重要性
- MMEB-V2为多模态嵌入提供全面评估
- 覆盖视频和文档任务填补空白

### 3. 视频嵌入的关键
- 均匀帧采样确保时间覆盖
- 时刻检索需要时间段候选匹配

### 4. 文档嵌入的挑战
- 视觉文档包含复杂布局和多种元素
- 需要处理表格、图表、排版等

---

## 总结

VLM2Vec-V2通过三大创新推进多模态嵌入技术：

1. **MMEB-V2基准**: 从36任务扩展到78任务，首次系统覆盖视频和文档检索
2. **统一嵌入模型**: 支持文本、图像、视频、文档四种模态的统一处理
3. **批次混合策略**: 解决多模态数据不平衡，增强对比学习效果

该工作为构建**通用视觉嵌入模型**提供了重要基础，使得单一模型能够统一理解图像、视频乃至复杂文档，为AI Agent、多模态搜索、RAG等实际应用提供了实用解决方案。
